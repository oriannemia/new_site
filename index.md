# Bienvenue

Ce site tient en **trois fichiers Markdown**. GitHub Pages les transforme en pages web à chaque `git push`.

- [À propos](a-propos.md) — qui fait ce site
- [Notes](notes.md) — un tableau, une liste, du code

## Comment ça marche

1. J'écris du Markdown dans un dépôt GitHub.
2. *Settings → Pages → Deploy from a branch* : GitHub en fait un site.
3. Chaque `git push` met le site à jour, en une minute environ.

Pas de serveur, pas de HTML écrit à la main. Blablablabla,
